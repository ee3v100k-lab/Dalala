# دلالة | سوق السودان الإلكتروني

منصة إعلانات مبوبة (Classifieds) كاملة الوظائف، مبنية بـ Node.js و Express و SQLite.
تدعم: نشر إعلانات بصور، بحث وفلترة حسب القسم والولاية، تسجيل دخول بسيط بالاسم ورقم الجوال، المفضلة، ومحادثات مباشرة بين البائع والمشتري.

---

## المتطلبات

- **Node.js** إصدار 18 أو أحدث ([حمّله من هنا](https://nodejs.org))
- **npm** (يأتي مع Node.js تلقائيًا)
- لا تحتاج أي قاعدة بيانات خارجية — المشروع يستخدم SQLite (ملف واحد محلي)

---

## التشغيل على جهازك (خطوة بخطوة)

```bash
# 1. ادخل مجلد المشروع
cd dalala

# 2. ثبّت المكتبات
npm install

# 3. جهّز ملف الإعدادات
cp .env.example .env
# افتح .env وغيّر SESSION_SECRET لأي نص عشوائي طويل

# 4. جهّز قاعدة البيانات (الأقسام والولايات)
npm run seed

# 5. شغّل السيرفر
npm start
```

بعد الخطوة الأخيرة، افتح المتصفح على:
**http://localhost:3000**

للتطوير مع إعادة التشغيل التلقائي عند أي تعديل، استخدم:
```bash
npm run dev
```
(يتطلب `nodemon`، وهو مضاف في devDependencies تلقائيًا).

## ملاحظات مهمة قبل النشر الفعلي (Production)

هذه نسخة أولى (MVP) جاهزة للاستخدام والتجربة، لكن قبل ما تطلقها للناس فعليًا، خذ بالك من النقاط دي:

1. **تسجيل الدخول مبسّط عن قصد** — بالاسم ورقم الجوال بدون كلمة سر أو تحقق OTP، زي ما طلبت. أي شخص يقدر يدخل بأي رقم. لو عايز حماية أقوى، أضف تحقق برسالة SMS (تحتاج خدمة مثل Twilio أو خدمة سودانية محلية) قبل تفعيل الحساب.
2. **الجلسات (Sessions)** محفوظة في ملف SQLite محلي — يشتغل تمام لسيرفر واحد. لو نويت تشغل أكثر من سيرفر (Load Balancing)، انقل الجلسات لـ Redis.
3. **الصور تُحفظ محليًا** في `public/uploads`. لو الموقع كبر، انقلها لخدمة تخزين سحابي (مثل S3 أو Cloudinary) بدل القرص المحلي.
4. **غيّر `SESSION_SECRET`** في ملف `.env` لقيمة عشوائية طويلة وسرّية قبل أي نشر فعلي.
5. **النسخ الاحتياطي**: ملف `db/dalala.sqlite` يحتوي كل بياناتك — خذ نسخة احتياطية منه بانتظام.
6. **HTTPS**: عند النشر على سيرفر حقيقي (VPS)، ضع الموقع خلف Nginx مع شهادة SSL مجانية من Let's Encrypt.

## النشر على سيرفر (مثال سريع بـ VPS)

```bash
# على السيرفر
git clone <رابط المشروع أو ارفع الملفات عبر scp>
cd dalala
npm install --production
cp .env.example .env   # وعدّل القيم
npm run seed
npm install -g pm2      # لتشغيل السيرفر باستمرار في الخلفية
pm2 start server.js --name dalala
pm2 save
```

بعدها اربط دومينك بالسيرفر عبر Nginx كـ reverse proxy على البورت المحدد في `.env`.

## أفكار لتطوير النسخة القادمة

- تحقق OTP فعلي عبر رسالة SMS
- تعديل الإعلان بعد نشره (حاليًا يمكن فقط حذفه أو تحديد حالته)
- ترتيب الإعلانات حسب السعر أو الأقرب
- إشعارات فورية بدل الاستطلاع الدوري (polling) في المحادثات — عبر WebSocket
- لوحة تحكم للإدارة لمراجعة الإعلانات المخالفة
