# دلالة | سوق السودان الإلكتروني

منصة إعلانات مبوبة (Classifieds) كاملة الوظائف، مبنية بـ Node.js و Express و SQLite.
تدعم: نشر إعلانات بصور، بحث وفلترة حسب القسم والولاية، تسجيل دخول بسيط بالاسم ورقم الجوال، المفضلة، ومحادثات مباشرة بين البائع والمشتري.

---

## المتطلبات

- **Node.js** إصدار 18 أو أحدث ([حمّله من هنا](https://nodejs.org))
- **npm** (يأتي مع Node.js تلقائيًا)
- لا تحتاج أي قاعدة بيانات خارجية — المشروع يستخدم SQLite (ملف واحد محلي)

---

## التشغيل على جهازك (خطوة بخطوة)

```bash
# 1. ادخل مجلد المشروع
cd dalala

# 2. ثبّت المكتبات
npm install

# 3. جهّز ملف الإعدادات
cp .env.example .env
# افتح .env وغيّر SESSION_SECRET لأي نص عشوائي طويل

# 4. جهّز قاعدة البيانات (الأقسام والولايات)
npm run seed

# 5. شغّل السيرفر
npm start
```

بعد الخطوة الأخيرة، افتح المتصفح على:
**http://localhost:3000**

للتطوير مع إعادة التشغيل التلقائي عند أي تعديل، استخدم:
```bash
npm run dev
```
(يتطلب `nodemon`، وهو مضاف في devDependencies تلقائيًا).

## هيكل المشروع

```
dalala/
├── server.js              # نقطة تشغيل السيرفر
├── db/
│   ├── schema.sql          # مخطط قاعدة البيانات
│   ├── index.js             # الاتصال بقاعدة البيانات
│   ├── seed.js               # تعبئة الأقسام والولايات
│   └── dalala.sqlite        # ملف القاعدة (يُنشأ تلقائيًا عند أول تشغيل)
├── middleware/
│   ├── auth.js              # التحقق من تسجيل الدخول
│   └── upload.js            # رفع الصور
├── routes/
│   ├── auth.js               # تسجيل الدخول/الخروج
│   ├── ads.js                 # الإعلانات (نشر، عرض، حذف، بحث)
│   ├── favorites.js         # المفضلة
│   └── messages.js         # المحادثات بين البائع والمشتري
├── views/                     # صفحات EJS
├── public/
│   ├── css/style.css         # التصميم
│   ├── js/                       # سكربتات المتصفح
│   └── uploads/               # صور الإعلانات المرفوعة
└── .env                          # إعداداتك الخاصة (لا تشاركه)
```

## ملاحظات مهمة قبل النشر الفعلي (Production)- تعديل الإعلان بعد نشره (حاليًا يمكن فقط حذفه أو تحديد حالته)
- ترتيب الإعلانات حسب السعر أو الأقرب
- إشعارات فورية بدل الاستطلاع الدوري (polling) في المحادثات — عبر WebSocket
- لوحة تحكم للإدارة لمراجعة الإعلانات المخالفة
